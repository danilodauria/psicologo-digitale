Scheda rapida

I passaggi che servono davvero, quattro per sistema. Stampa questa pagina e tienila accanto al computer: le istruzioni complete e le domande frequenti restano in Come si installa.

Scarica il PDF Istruzioni complete

Windows

  1. Scarica Psicologo-Digitale-Windows-x64.exe, oppure lo ZIP portatile.
  2. Doppio clic. Se compare Windows ha protetto il PC: Altro informazioni → Esegui comunque.
  3. Se il file resta fermo prima di partire: tasto destro → Proprietà → in fondo Sblocca → OK.
  4. Completa l'installazione: da lì si apre dal menu avvio.

L'avviso può tornare a ogni versione nuova: non è un errore. Lo ZIP portatile non installa nulla, si scompatta e si avvia.

macOS

  1. Scarica il .dmg giusto: Mac-arm64 per Apple Silicon, Mac-x64 per Intel.
  2. Apri il .dmg e trascina Psicologo Digitale in Applicazioni.
  3. Doppio clic sull'app, premi Fine (non Sposta nel cestino).
  4. Impostazioni di Sistema → Privacy e sicurezza → in fondo, sotto Sicurezza, Apri comunque → password o Touch ID.

Se Apri comunque non c'è, riapri l'app e torna lì: la voce compare solo dopo un tentativo bloccato, e resta circa un'ora.

Linux

  1. .deb: doppio clic, oppure sudo apt install ./Psicologo-Digitale-Linux-amd64.deb.
  2. AppImage: chmod +x Psicologo-Digitale-Linux-x86_64.AppImage, poi doppio clic (o tasto destro → Proprietà → consenti l'esecuzione).
  3. Se manca FUSE: --appimage-extract-and-run dopo il nome del file.
  4. Nessun avviso di sicurezza da superare: il pacchetto funziona così com'è.

Su tutte e tre le strade il programma può essere usato anche senza installare niente, dal browser: apri il programma.

La connessione serve solo per scaricare. Dopo, il programma funziona offline e i dati restano sul dispositivo: nessun server li riceve. Se un passaggio non torna, le risposte sono nelle domande frequenti.

Avvertenza. È uno strumento educativo e di orientamento: non formula diagnosi, non prescrive terapie e non sostituisce il parere di uno psicologo, di uno psicoterapeuta o di un medico. In caso di emergenza chiama il 112.
